## Default Permission

Allows the PicBind main window to manage native realtime peers.

#### This default permission set includes the following:

- `allow-realtime-peer-create`
- `allow-realtime-peer-create-offer`
- `allow-realtime-peer-create-answer`
- `allow-realtime-peer-set-local-description`
- `allow-realtime-peer-set-remote-description`
- `allow-realtime-peer-add-ice-candidate`
- `allow-realtime-peer-send`
- `allow-realtime-peer-buffered-amount`
- `allow-realtime-peer-close`
- `allow-realtime-session-close`
